# 📚 Library Management System

A web-based Library Management System designed to efficiently manage books, users, and issue/return operations within a library.

## 🚀 Features
- Add, update, and delete book records
- Manage library users
- Book issue and return management
- Track available and issued books
- Simple and user-friendly interface
- Organized database management

## 🛠 Tech Stack
- Python / Django (Backend)
- HTML, CSS, Bootstrap (Frontend)
- SQLite (Database)

## 📂 Project Structure
Library-Management/
│── library/
│── templates/
│── static/
│── db.sqlite3
│── manage.py

## ⚙️ Installation & Setup

1. Clone the repository
git clone https://github.com/kshitiz-2003/Library-Management.git

Navigate to project folder
cd Library-Management

Install dependencies
pip install -r requirements.txt

Run migrations
python manage.py migrate

Start the server
python manage.py runserver

Open browser and visit
http://127.0.0.1:8000/

🎯 Usage
The system allows librarians/admins to manage books and users while keeping track of issued and returned books efficiently.
